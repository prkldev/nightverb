# Nightverb: таск-лист

Цель: выкатить для людей в каталог Firefox (AMO), всё в одном: замедление + реверб.

## 1. Замедление (главное на завтра)

- [x] Ползунок "Скорость" 0.5x-1.5x в попапе + быстрые кнопки 0.75 / 0.8 / 0.85 / 0.9 / 1x
- [x] Переключатель "Тон вместе со скоростью" (вкл = настоящий slowed, звук ниже; выкл = только темп)
- [x] Скрипт в каждой вкладке (`page.js`, мир страницы): `playbackRate` + `preservesPitch` для всех `<audio>`/`<video>`
- [x] Плееры вне DOM (`new Audio()`), в shadow DOM, с autoplay: ловятся (перехват `play()` и `attachShadow`)
- [x] Плеер не может сбросить скорость: сайт видит "свои" значения, реальная скорость наша (проверено "вредным" плеером, который ставит 1x каждые 100 мс)
- [x] Звонки (MediaStream) не трогаются
- [x] Скорость в полутонах: кнопки -2 / -3 / -4 / -5 / -7 / -12 (октава) / 1x, подпись "-4 полутона", ползунок прилипает к ровным нотам
- [x] Пресеты Slowed + Reverb (-4), Vapor (-3), Космос (-5) ставят скорость; остальные её не трогают
- [x] Горячие клавиши: Alt+Shift+R всё вкл/выкл, Alt+Shift+↑/↓ на полутон
- [x] Новое лого: полумесяц + дуги эха
- [x] Вкл/выкл замедления и реверба по отдельности + общий выключатель
- [x] Замедление работает без помощника; реверб без помощника показывает инструкцию
- [x] Автотест: `tools/speed-test.html` (6 видов плееров, вкл и выкл), все проходят
- [ ] Проверить на живых сайтах: Яндекс Музыка, Spotify, YouTube, SoundCloud, VK Музыка
- [ ] Локальные файлы (file://) скрипт не получает: решить, нужно ли (разрешение на file:// в Firefox MV3)

## 1.5 Встроенный реверб (без программы)

- [x] Реверб внутри расширения (Web Audio, свёртка с генерируемым импульсом) для открытых сайтов, любая ОС
- [x] Защищённый (DRM) и чужой без CORS звук не трогается, иначе он бы замолчал; сайты со своим Web Audio тоже не трогаются
- [x] Компонент установлен и включён: он делает реверб везде, встроенный выключается (без двойного реверба)
- [x] На защищённых сайтах плашка "Скачать аудиокомпонент", после запуска файла окошко само находит компонент
- [x] Автотест `tools/reverb-test.html`: 3 подключены, 1 правильно пропущен и играет, хвост слышен в захвате
- [x] Диагностика конфликтов `tools/conflict-test.ps1`: нет двойного реверба, компонент пропал -> встроенный подхватывает за минуту (фоновая проверка), громкость совпадает (`tools/calibrate-builtin.mjs`, ±1 дБ по пресетам)
- [x] Яндекс Музыка строит свой Web Audio-граф, значит звук без DRM: реверб встраивается в граф сайта (`tools/webaudio-test.html` проходит). Подтвердить на слух на живом Яндексе
- [x] Установщик: тихий, сообщение закрывается само через 4 с
- [x] Git-репозиторий, лицензия MIT, CI-сборка и релизы (`.github/workflows/build.yml`), тексты и скриншоты для AMO (`docs/store/`)
